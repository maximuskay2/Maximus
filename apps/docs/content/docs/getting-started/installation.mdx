## Install an agent CLI

Maximus needs at least one supported agent engine installed and signed in. Claude and Codex are the most common starting points.

1. Install the CLI from its official provider.
2. Run it once in a terminal and complete sign-in.
3. Restart Maximus.
4. Open the model picker. Available engines appear normally; unavailable engines explain what is missing.

See [Agent engines](../providers/index.mdx) for the complete list and explicit path overrides.

## Using Maximus at work

If your company uses Maximus Admin, you can sign in with your organization to use the AI models it provides, alongside your own. It is optional. See [Use Maximus at work](./organisation.mdx).

## Build from source

Requirements: Node.js 24 or newer, pnpm 10.33.0, and at least one authenticated agent CLI.

```bash
git clone https://github.com/RELEASE_OWNER/Maximus.git
cd Maximus
corepack enable
pnpm install --frozen-lockfile
```

Run the harness, web UI, and Electron shell in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

Maximus stores its application data under `~/.maximus`. Electron window and browser data use the normal per-platform application data directory.

Upgrading from OpenMausBot: first launch copies `~/.openmausbot` to `~/.maximus` and verifies every file landed; the old directory is left in place.
